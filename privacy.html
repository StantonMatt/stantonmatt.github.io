Privacy policy

Last updated: October 16, 2026

Personal MCP Gateway is private software operated by me, Matthew Stanton, on my own computer, bound to localhost. I am its only user, and it connects only to my own Google accounts.

Google data and use

The gateway uses Google OAuth to access Gmail email and basic Gmail settings. It requests these scopes:

  • https://mail.google.com/
  • https://www.googleapis.com/auth/gmail.settings.basic

This access lets my local AI agents, including Claude Code and Codex, read, search, draft and manage my email and basic Gmail settings on my behalf.

Storage and sharing

Gmail data and OAuth tokens are stored only on my machine. Tokens are encrypted at rest. No servers operated by me receive this data.

Email content is passed only to the AI agent I am using at that moment, at my request. Apart from that requested transfer, the gateway does not share Gmail data. It does not sell the data, use it for advertising, or use it to train generalized AI or machine learning models.

Retention and deletion

Gmail data remains on my machine for my personal use, and I can delete locally stored data there. Disconnecting a Google account in the gateway deletes its stored OAuth tokens.

Google account access can be revoked at any time through Google Account permissions.

Google API policy

Personal MCP Gateway's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
